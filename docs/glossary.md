# Project Glossary
## T042-PS-040: Cinema and Event Ticketing with Seat Holds and Dynamic Pricing

| Term | Description |
|---|---|
| Booking | A confirmed reservation of cinema seats. |
| Seat Hold | Temporary reservation of seats for 8 minutes. |
| Dynamic Pricing | Adjusting ticket prices according to seat occupancy. |
| Occupancy | Percentage of seats already occupied or booked. |
| Show | A scheduled movie or event screening. |
| Venue | The location where a movie or event takes place. |
| Screen | The individual cinema auditorium. |
| Seat | An individual seating position in a screen. |
| Presold Seat | A seat already sold before the booking process. |
| Classic | A standard ticket category. |
| Prime | A premium ticket category. |
| Recliner | A seat with reclining facilities. |
| GST | Goods and Services Tax applied to ticket prices and fees. |
| Convenience Fee | An additional charge applied to each ticket. |
| Loyalty Points | Reward points earned through eligible bookings. |
| Refund | Money returned after an eligible cancellation. |
| Contiguous Seats | Consecutive seats located next to each other in one row. |
| Expiry | The end of a temporary seat hold after its permitted duration. |
| SQLite | A lightweight relational database used by the application. |
| Pytest | A Python framework used to execute automated tests. |
| CSV | Comma-Separated Values file format used for reports. |
| Business Rule | A condition that defines how the ticketing system must operate. |
| Command Processor | Module responsible for processing booking commands. |
